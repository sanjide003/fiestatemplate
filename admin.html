User Guide

Learn every mode, role and workspace in this application.

1. Start here

  1. Complete Master Setup and choose the operating mode.
  2. Create teams, categories, scoring rules and user access.
  3. Add students/participants and events, then open registrations.
  4. Prepare the schedule and judging assignments when those capabilities are enabled.
  5. Publish results; public pages, Team Portal and TV update from Firestore.

Basic mode

Use a simple ordered programme list with core registration, publishing and team totals. Best for small festivals that do not need dates, stages or judge assignment.

Advanced mode

Enables dated multi-stage schedules, schedule review/print, registration locks, judging, publisher review and detailed operational controls.

2. Admin workspaces

People & Registration

Approve requests; manage students, parents, staff, guests and entries.

Programme & Judging

Create events, build schedules, print versions and assign judges.

Festival Configuration

Set master capabilities, teams, scoring and role access.

Public & Display

Control public wording, branding, Team Portal content and Fest TV.

Poster & Certificate

Configure fixed poster, certificate and ID-card layouts inside Admin.

System

Use the page directory, reset tools and this guide.

3. Roles and workflow

Admin: full configuration and operational control.

Team Leader: team-scoped registrations, schedule, reports and allowed downloads.

Judge: assigned programme score sheets and submission.

Publisher: verifies and publishes results.

Media Editor: template and media workspace without full Admin access.

Safe operation

Configure access before sharing links, preview schedule/results before publishing, keep TV videos muted, and use Data Reset only after reviewing the confirmation and record count.
